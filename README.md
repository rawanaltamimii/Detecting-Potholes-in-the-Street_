# مسار تجارب الرؤية الحاسوبية والتصنيف

لوحة ألوان مقترحة للواجهة أو البطاقات التعريفية: أبيض ناعم `#FAF9F6` · بيج دافئ `#EFECE6` · أخضر مريمي هادئ `#7A9A86` · رمادي فحمي ناعم `#2E3532`.

نظرة عامة منظمة وهادئة على تجربتين عمليتين في تعلم الآلة والرؤية الحاسوبية: نموذج تصنيف ثنائي مع تحليل مصفوفة الارتباك، ونموذج تقسيم وكشف الحفر (`pothole`) باستخدام `YOLOv8 Segmentation`.

---

## التجربة الأولى: التصنيف وتحليل مصفوفة الارتباك

تُظهر مخرجات نوتبوك `سوسن` تقييم نموذج تصنيف ثنائي (الصنف `0` والصنف `1`) على إجمالي **136** عينة، مع تجهيز دوال حساب `Precision` و`Recall` و`F1-score` لكل صنف.

### ملخص مصفوفة الارتباك

| الفعلي \ المتوقع | الصنف `0` | الصنف `1` | قراءة مختصرة |
| :--- | :---: | :---: | :--- |
| **الصنف `0`** | **69** | **0** | لا توجد حالات من الصنف `0` صُنّفت كـ `1` |
| **الصنف `1`** | **13** | **54** | **13** حالة حقيقية ذهبت إلى الصنف `0` |

* **الدقة الإجمالية (`Accuracy`):** حوالي **90.44%** (`123 / 136`)
* **نقطة القوة:** صفاء التنبؤ بالصنف `1` واستقرار التنبؤ بالصنف `0` دون خلط في الاتجاه المعاكس
* **نقطة التحسين:** تقليل الحالات الـ **13** التي انتقلت من الصنف `1` إلى الصنف `0`

## التجربة الثانية: تقسيم وكشف الحفر (`YOLOv8 Segmentation`)

تُظهر مخرجات التقييم إعداد النموذج لصنف واحد (`0: pothole`) واختباره على مجموعة تحقق تضم **60 صورة** و**201 حالة**.

### ملخص مقاييس الأداء

| المقياس | القيمة الظاهرة | الدلالة العملية |
| :--- | :---: | :--- |
| **`mAP50`** | `0.746` *(ومسجّل `74.83%`)* | أداء جيد في تحديد مواقع الحفر عند عتبة `0.50` |
| **`mAP50-95`** | `0.453` | يعكس دقة مطابقة الحواف غير المنتظمة عند العتبات الأعلى |
| **Box Precision** | `0.67` | دقة الصناديق المحيطة بالحفر |
| **Recall (`R`)** | `0.706` | قدرة النموذج على التقاط الحفر الفعلية |
| **Mask Precision** | `0.667` | اتساق القناع (`Mask`) مع حدود الكشف |
| **زمن الاستدلال للصورة** | `208.5ms` | معالجة مسبقة `7.3ms` ومعالجة لاحقة `41.8ms` |

* **ملاحظة بصرية:** يبرز الماسك (`Mask`) مواقع الحفر بوضوح على عينة التحقق، مع ظهور تقارب وتزاحم في التسميات عندما تتقارب الحفر داخل المشهد.
